# 🎬 Janonify — Remotion Video Engine (অসমীয়া)

**Janonify** হৈছে এটা স্বয়ংক্ৰিয় আৰু কনফিগাৰেচন-ভিত্তিক চুটি মোশন গ্ৰাফিক্স ভিডিঅ’ ইঞ্জিন। এইটো **Remotion**, **React** আৰু **TypeScript** ব্যৱহাৰ কৰি অসমীয়া ভাষাত তথ্যসমৃদ্ধ আৰু শিক্ষামূলক ভিডিঅ’ (যেনে: *"জানেনে বাৰু?"* / ফেক্ট আৰু তথ্যমূলক ভিডিঅ’) সহজে আৰু দ্ৰুতভাৱে সৃষ্টি কৰিবলৈ সাজু কৰা হৈছে।

---

## 🚀 মূল সুবিধাসমূহ (Key Features)

- 📱 **9:16 উলম্ব ভিডিঅ’ (1080x1920):** YouTube Shorts, Instagram Reels আৰু TikTok-ৰ বাবে উপযুক্ত 30/60 FPS ফুল HD ৰেণ্ডাৰ।
- 🎙️ **কাৰাওকে চাবটাইটেল (Karaoke Subtitles):** শব্দভিত্তিক হাইলাইট আৰু মসৃণ বাউন্স এনিমেচনৰ সৈতে স্বয়ংক্ৰিয়ভাৱে মিলি যোৱা অসমীয়া চাবটাইটেল।
- 🎭 **আকৰ্ষণীয় চৰিত্ৰ এনিমেচন (Character Animation):** বক্তা/চৰিত্ৰৰ বিভিন্ন ভংগীমা (Left, Right, Thoughtful, Staff, Outward আদি) সময় অনুসৰি সলনি হোৱা ব্যৱস্থা।
- 📊 **গতিশীল মোশন গ্ৰাফিক্স (Dynamic Motion Graphics):** বিষয় আৰু ব্যাখ্যাৰ সৈতে খাপ খোৱা চিত্ৰ, ডায়াগ্ৰাম আৰু তথ্য কাৰ্ড।
- 🔊 **শব্দ প্ৰভাৱ (Sound Effects Engine):** প্ৰতিটো পৰিৱৰ্তনত পপ, হুচ আৰু টাইমাৰৰ সঠিক শব্দ সংমিশ্ৰণ।
- ⚙️ **কনফিগ-চালিত গাঁথনি (Config-Driven Architecture):** কেৱল `templateConfig.ts` আৰু `transcriptData.ts` সলনি কৰিয়েই যিকোনো নতুন অসমীয়া ভিডিঅ’ প্ৰস্তুত কৰিব পাৰি।

## 🛠️ আৰম্ভণি আৰু ব্যৱহাৰ (Quick Start)

### ১. প্ৰয়োজনীয় পেকেজসমূহ ইনষ্টল কৰক
প্ৰকল্পৰ ফোল্ডাৰত টাৰ্মিনেল খুলি এই কমাণ্ডটো চলাওক:
```bash
npm install
```

### ২. Remotion Studio আৰম্ভ কৰক (লাইভ প্ৰিভিউ)
ব্ৰাউজাৰত লাইভ প্ৰিভিউ চাবলৈ:
```bash
npm run studio
```
ষ্টুডিঅ’টো আপোনাৰ ব্ৰাউজাৰত `http://localhost:3000`-ত খোল খাব।

### ৩. ভিডিঅ’ ৰেণ্ডাৰ / এক্সপ’ৰ্ট কৰক
চূড়ান্ত 1080x1920 MP4 ভিডিঅ’ ৰেণ্ডাৰ কৰিবলৈ:
```bash
npm run render
```
ৰেণ্ডাৰ হোৱা ভিডিঅ’টো `out/` ফোল্ডাৰত জমা হ’ব।

## 🎨 নতুন অসমীয়া ভিডিঅ’ নিৰ্মাণৰ নিয়ম (Workflow)

১. **অডিঅ’ আৰু ছবি সংযোগ কৰক:**
   - নতুন অসমীয়া কণ্ঠস্বৰ অডিঅ’টো `public/voiceover.wav` নামেৰে প্ৰতিস্থাপন কৰক।
   - প্ৰয়োজনীয় কাৰ্ড আৰু ছবিসমূহ `public/` ফোল্ডাৰত ৰাখক।

২. **সময় আৰু কনফিগাৰেচন ছেট কৰক (`src/templateConfig.ts`):**
   - ভিডিঅ’ৰ মুঠ সময়সীমা (`durationInSeconds`) দিয়ক।
   - মূল শিৰোনাম (`mainTitle`: যেনে *"জানেনে বাৰু?"*) দিয়ক।
   - `keyPoints`-ত টাইমক’ড অনুসৰি চৰিত্ৰৰ ভংগীমা আৰু ফ’কাচ কাৰ্ড সংহতি কৰক।

৩. **চাবটাইটেল আপডেট কৰক (`src/transcriptData.ts`):**
   - আপোনাৰ কণ্ঠস্বৰৰ অসমীয়া বাক্য আৰু শব্দ অনুসৰি টাইমক’ড সংহতি কৰক।

৪. **প্ৰিভিউ চাই ৰেণ্ডাৰ দিয়ক:**
   - ষ্টুডিঅ’ত প্ৰিভিউ সঠিক দেখিলে `npm run render` চলাই ভিডিঅ’টি প্ৰস্তুত কৰক।
